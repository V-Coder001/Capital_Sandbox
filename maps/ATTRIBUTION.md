# Kartenquellen

## San Francisco (`sanfrancisco.json`)

Abgeleitet aus einem Export von [topoexport.com](https://topoexport.com),
Ausschnitt 1167 × 1167 m um 37,795 N / 122,394 W — die Auffahrt zur Bay Bridge.
Erzeugt mit `tools/build-sf-map.py`.

Die zugrunde liegende Geometrie stammt aus:

| Ebene | Quelle | Lizenz |
|---|---|---|
| Strassen, Gebaeude, Wasserlaeufe, Gruenflaechen, Baeume | Overture Maps Foundation 2026 | **ODbL** |
| Gelaendemodell (1 m) | USGS 3D Elevation Program 2026 | Public Domain |
| Baumhoehen | Meta / World Resources Institute, Global Canopy Height Maps v2 | CC BY 4.0 |

**Was die ODbL verlangt.** Die Namensnennung oben muss fuer Spieler sichtbar
bleiben — sie steht im Spiel unter *Lexikon → Karte*. Die ODbL ist ausserdem
share-alike: `sanfrancisco.json` ist eine abgeleitete Datenbank und muss unter
denselben Bedingungen weitergegeben werden. Das betrifft die Kartendatei, nicht
den uebrigen Spielcode.

Wer die Karte durch eine selbst gezeichnete ersetzt, kann diesen Abschnitt
streichen — die Verpflichtung haengt allein an dieser Datei.
