Version wird geladen …

Beim ersten Start warnt das System. Die App ist noch nicht signiert, deshalb meldet macOS „nicht verifizierter Entwickler" (Rechtsklick auf die App → Öffnen) und Windows zeigt den SmartScreen-Hinweis (Weitere Informationen → Trotzdem ausführen). Das ist bei jeder unsignierten App so und sagt nichts über Schadsoftware aus.

Lieber ohne Download?

Das Spiel läuft auch direkt im Browser — dieselbe Welt, nur mit auf die Leitung abgestimmter Grafik. Hier geht es zum Spiel.

Online mit Freunden

In der Desktop-App gibt es auf dem Startbildschirm drei Wege: eine Runde auf deinem Rechner (für dich allein oder fürs eigene WLAN), eine Online-Runde erstellen über unseren Server, oder einer bestehenden Runde mit dem Code deiner Freunde beitreten.
